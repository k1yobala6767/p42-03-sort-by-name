## Условие

Продолжение Заданий 7–8. Готовые файлы Student.cs и SampleData.cs менять нельзя.

Напишите в Program.cs три метода:
1) SortByName(students) сортирует массив студентов по имени (Name) в алфавитном порядке прямо в этом массиве. Сравнение строк: string.Compare(a.Name, b.Name) < 0 означает, что a стоит раньше b. Сортировку напишите сами (например, пузырьком), меняя местами элементы массива; Array.Sort и LINQ не используйте.
2) FindHigh(group, minAverage): перенесите свой метод из Задания 8 (студенты, у которых есть оценки и Average >= minAverage, в новом массиве).
3) HighSortedByName(group, minAverage) возвращает студентов с высоким баллом по алфавиту: найти через FindHigh, отсортировать через SortByName. Исходный массив group должен остаться в прежнем порядке.

Подумайте, почему сортировка результата FindHigh не меняет порядок в group, хотя в обоих массивах лежат одни и те же объекты.

**Примеры**

```
SortByName(Ким Анна, Ким Алексей, Ахметова Айгерим) → Ахметова Айгерим, Ким Алексей, Ким Анна
Пояснение: при одинаковой фамилии сравнивается имя («Ал» раньше «Ан»)

SortByName(вся группа) → Ахметова Айгерим, Бекова Мадина, Денисова Ольга, Жумабаев Нурлан, Ким Анна, Ли Виктор, Петровых Александр, Сериков Дамир

HighSortedByName(group, 85) → Ахметова Айгерим, Денисова Ольга, Жумабаев Нурлан, Ким Анна
После вызова group по-прежнему: Сериков Дамир, Ахметова Айгерим, Ким Анна, …
```

## Как выполнить

1. Один человек из команды нажимает **Fork** (вверху справа) и добавляет напарника: Settings → Collaborators → Add people.
2. Оба клонируют форк и открывают его в VS Code:
   ```
   git clone https://github.com/<ваш-ник>/p42-03-sort-by-name
   cd p42-03-sort-by-name
   code .
   ```
3. Впишите в таблицу «Команда» выше свои ФИО и ники GitHub.
4. В `Program.cs` напишите решение внутри методов `SortByName`, `FindHigh` и `HighSortedByName` (вместо строк `// TODO`). Не меняйте `Student.cs`, `SampleData.cs` и методы `Main`, `Check`, `Names`.
5. Запустите:
   ```
   dotnet run
   ```
   Все проверки должны показать `OK`.
6. Сохраните работу в GitHub (коммитят оба участника):
   ```
   git add .
   git commit -m "Решение"
   git push
   ```
